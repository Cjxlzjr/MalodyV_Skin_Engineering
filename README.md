# malodyv-lua

一个面向 **MalodyV 皮肤工程** 的知识仓库，主要用于沉淀任务约束、参考资料与测试提示，帮助在修改/审查 MalodyV Lua 与 Composer 相关内容时保持一致性与可验证性。

## 仓库内容

- `SKILL.md`：核心工作准则与适用范围说明。
- `references/`：按主题整理的参考文档（运行时、Composer、验证、性能、安全边界等）。
- `test-prompts.json`：测试场景与期望结果样例集合。
- `agents/openai.yaml`：代理展示信息与默认提示配置。

## 使用方式（建议）

1. 先阅读 `SKILL.md`，确认任务是否在该仓库技能范围内。
2. 根据任务类型查阅 `references/` 对应主题文档。
3. 需要回归或验证提示时，参考 `test-prompts.json` 中的场景与期望。

## 适合的任务类型

- MalodyV 皮肤 Lua 回调与行为分析
- Composer / `info.asm` 结构与约束核对
- 运行时时钟、判定、性能与验证流程梳理
- 文档化规则维护与证据边界审查

## 说明

本仓库更偏向“参考与规范”性质，不是完整可执行项目模板。进行实际皮肤开发时，请结合你的目标版本、平台和模式进行实机验证。
